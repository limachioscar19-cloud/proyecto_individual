Toast y Notificaciones Asíncronas

Sistema de alertas emergentes animadas no bloqueantes con temporizador y auto-ocultación.

📍 Aplicación: Se aplica al agregar productos al carrito, guardar precios o actualizar estados de comanda.

Código Implementado en esta Fase: 
let tTimer;
        document.getElementById('btnLanzarToast').addEventListener('click', () => {
            const t = document.getElementById('toastFase');
            clearTimeout(tTimer);
            t.textContent = '✓ Plato agregado al carrito con éxito';
            t.style.display = 'block';
            tTimer = setTimeout(() => { t.style.display = 'none'; }, 2400);
        });
