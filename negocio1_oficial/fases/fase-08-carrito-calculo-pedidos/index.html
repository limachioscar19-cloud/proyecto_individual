Carrito de Compras y Cálculo de Pedidos

Gestión de estado del carrito con sumatoria automática de cantidades y cálculo de total en bolivianos.

📍 Aplicación: Se aplica en el panel lateral 'Mi pedido' y el formulario de checkout hacia WhatsApp.

Total a Pagar: 0 Bs
Código Implementado en esta Fase: 
let cartItems = [];
        function renderCart() {
            const cont = document.getElementById('itemsCarrito');
            cont.innerHTML = cartItems.map((item, i) => '<div style="display:flex; justify-content:space-between; margin:4px 0;"><span>' + item.name + ' x ' + item.qty + '</span><b>' + (item.price * item.qty) + ' Bs</b></div>').join('');
            const total = cartItems.reduce((acc, item) => acc + (item.price * item.qty), 0);
            document.getElementById('totalCarrito').textContent = total + ' Bs';
        }
        document.getElementById('addAlm').addEventListener('click', () => {
            const ex = cartItems.find(i => i.name === 'Almuerzo completo');
            if (ex) ex.qty++; else cartItems.push({ name: 'Almuerzo completo', price: 20, qty: 1 });
            renderCart();
        });
        document.getElementById('addEsp').addEventListener('click', () => {
            const ex = cartItems.find(i => i.name === 'Plato especial');
            if (ex) ex.qty++; else cartItems.push({ name: 'Plato especial', price: 40, qty: 1 });
            renderCart();
        });
