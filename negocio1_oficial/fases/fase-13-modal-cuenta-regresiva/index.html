Modal con Cuenta Regresiva (Temporizador)

Ventana modal con cuenta regresiva asíncrona mediante setInterval y clearInterval para redirección a WhatsApp.

📍 Aplicación: Se aplica tras confirmar el formulario de pedido del restaurante antes de abrir el enlace.

¡Comanda Registrada!

Redirigiendo a WhatsApp en:

5
Código Implementado en esta Fase: 
let timerId = null;
        document.getElementById('btnIniciarCuenta').addEventListener('click', () => {
            const modal = document.getElementById('modalCuenta');
            const num = document.getElementById('numeroCuenta');
            modal.style.display = 'block';
            let seg = 5;
            num.textContent = seg;
            clearInterval(timerId);
            timerId = setInterval(() => {
                seg--;
                num.textContent = seg;
                if (seg <= 0) {
                    clearInterval(timerId);
                    modal.innerHTML = '<p style="color:var(--green-dark); font-weight:800;">¡Redirigiendo a WhatsApp ahora!</p>';
                }
            }, 1000);
        });
        document.getElementById('btnDetenerCuenta').addEventListener('click', () => {
            clearInterval(timerId);
            document.getElementById('modalCuenta').style.display = 'none';
        });
