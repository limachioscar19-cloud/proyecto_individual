jQuery y Acordeones Fluidos

Despliegue suave con slideToggle(220) y stop(true, true) para no saturar la cola de animaciones.

📍 Aplicación: Se aplica en las tarjetas de días del menú semanal para abrir los detalles de sopas y segundos.

🍲 Sopa: Sopa de arroz con maní (7 Bs)

🍗 Segundo 1: Milanesa de pollo (15 Bs)

🥘 Segundo 2: Saice tarijeño (15 Bs)

Código Implementado en esta Fase: 
if (window.jQuery) {
            $('.acordeon-header').on('click', function() {
                const body = $(this).next('.acordeon-body');
                const signo = $(this).find('.signo');
                body.stop(true, true).slideToggle(220, function() {
                    signo.text(body.is(':visible') ? '−' : '+');
                });
            });
        }
