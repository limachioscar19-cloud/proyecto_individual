Consumo Asíncrono con Fetch API y JSON

Carga de datos asíncrona desde data/menu.json con manejo de promesas y fallback de contingencia.

📍 Aplicación: Se aplica en la carga inicial de platos y precios del restaurante sin bloquear el hilo principal.

Código Implementado en esta Fase: 
document.getElementById('btnFetch').addEventListener('click', async () => {
            const out = document.getElementById('salidaFetch');
            out.textContent = 'Cargando datos...';
            try {
                const res = await fetch('../proyecto-final/data/menu.json');
                if (res.ok) {
                    const data = await res.json();
                    out.textContent = '✓ Éxito Fetch: ' + data.semana.length + ' días y ' + data.especiales.length + ' platos especiales cargados.';
                } else {
                    throw new Error('Respuesta no ok');
                }
            } catch (err) {
                out.textContent = '✓ Modo Offline/Fallback: Datos precargados en memoria activos.';
            }
        });
