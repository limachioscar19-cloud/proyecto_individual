Lazy Loading y Zoom Accesible (Lightbox)

Descarga diferida de imágenes con loading='lazy' y ampliación modal accesible con soporte de tecla Escape.

📍 Aplicación: Se aplica en la galería de platos especiales y carrusel de fotografías.

Haz clic en la imagen para abrir el lightbox modal:

Código Implementado en esta Fase: 
const img = document.getElementById('imgZoomDemo');
        const box = document.getElementById('lightboxFase');
        const big = document.getElementById('imgLightboxGrande');
        img.addEventListener('click', () => {
            big.src = img.src;
            box.style.display = 'flex';
        });
        function cerrar() { box.style.display = 'none'; }
        document.getElementById('btnCerrarLightbox').addEventListener('click', cerrar);
        document.addEventListener('keydown', e => { if (e.key === 'Escape') cerrar(); });
