Vistas Diferenciadas por Rol

Arquitectura basada en perfiles (Cliente, Empleado y Gerente) con navegación y permisos adaptados a cada rol.

📍 Aplicación: Se aplica en el sistema de autenticación y paneles operativos del restaurante.

Código Implementado en esta Fase: 
const p = document.getElementById('panelRol');
        function ver(rol) {
            if (rol === 'cliente') {
                p.innerHTML = '<h4>👤 Vista Cliente</h4><p>Acceso al catálogo de platos, pedidos por WhatsApp y ubicación.</p>';
            } else if (rol === 'empleado') {
                p.innerHTML = '<h4>👨‍🍳 Vista Empleado (Cocina)</h4><p>Recepción de comandas, avance de preparación y marcado de platos listos.</p>';
            } else {
                p.innerHTML = '<h4>👑 Vista Gerente (Admin)</h4><p>Gestión de precios, bitácora de auditoría, estados financieros y smoke testing.</p>';
            }
        }
        document.getElementById('rolCliente').addEventListener('click', () => ver('cliente'));
        document.getElementById('rolEmpleado').addEventListener('click', () => ver('empleado'));
        document.getElementById('rolGerente').addEventListener('click', () => ver('gerente'));
        ver('cliente');
