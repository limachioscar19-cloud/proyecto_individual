Eventos y Delegación (Event Bubbling)

Delegación global de eventos para evitar fuga de memoria RAM y manejar elementos creados dinámicamente.

📍 Aplicación: Se aplica en el carrito de compras para eliminar platos y en la selección de opciones de menú.

Código Implementado en esta Fase: 
let contId = 1;
        document.getElementById('btnAgregarDinamico').addEventListener('click', () => {
            const div = document.createElement('div');
            div.style.cssText = 'display:flex; justify-content:space-between; align-items:center; background:var(--card); padding:8px 14px; border-radius:6px; border:1px solid var(--line);';
            div.innerHTML = '<span>Plato agregado #' + contId++ + '</span><button class="btn-eliminar" style="background:#d9534f; color:#fff; border:0; padding:6px 12px; border-radius:15px; cursor:pointer;">Eliminar</button>';
            document.getElementById('contenedorFilas').appendChild(div);
        });
        document.getElementById('contenedorFilas').addEventListener('click', (e) => {
            if (e.target.classList.contains('btn-eliminar')) {
                e.target.closest('div').remove();
            }
        });
