Modo Oscuro y Claro Dinámico

Alternancia instantánea de tema mediante variables CSS personalizadas y persistencia en localStorage.

📍 Aplicación: Se aplica en toda la interfaz de usuario para permitir lectura cómoda tanto de día como de noche.

Control de Tema del Restaurante

Cambia el tema visual instantáneamente. El estado se almacena en el navegador:

Tema actual: Claro

Código Implementado en esta Fase: 
const btnTema = document.getElementById('btnTema');
        const temaInfo = document.getElementById('temaInfo');
        function aplicar(oscuro) {
            document.body.classList.toggle('dark-mode', oscuro);
            btnTema.textContent = oscuro ? 'Cambiar a Modo Claro ☀' : 'Cambiar a Modo Oscuro ☼';
            temaInfo.textContent = 'Tema actual: ' + (oscuro ? 'Oscuro' : 'Claro');
            localStorage.setItem('chamaca_tema_fase', oscuro ? 'dark' : 'light');
        }
        btnTema.addEventListener('click', () => aplicar(!document.body.classList.contains('dark-mode')));
        if (localStorage.getItem('chamaca_tema_fase') === 'dark') aplicar(true);
